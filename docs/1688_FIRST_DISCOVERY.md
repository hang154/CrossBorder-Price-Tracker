# 1688 선행 전 범주 탐색

`scripts/1688_first_discovery.py`는 기존 OpenCLI 1688 카드 정규화와 쿠팡 홈 검색, 로컬 Qwen 도구 호출을 연결한다. 분류를 수동 제한하지 않고 실행 시점 1688 홈에서 관측한 공식 대분류 링크 전체를 저장한다. 하위 분류나 전체 SKU의 완전 수집을 뜻하지 않는다.

1. 1688 홈 원문 및 분류 링크/해시 저장
2. 모든 관측 분류의 실제 상품 카드 수집: 기본 분류당 최대 20개
3. Qwen이 관측 ID와 정확한 상품명 인용으로 분류당 최대 3개 쿠팡 비교 검색어 선정
4. 1688 수집 단계 후 쿠팡 홈 → 검색창 → 실제 상품 목록 탐색
5. Qwen이 원본/국내 사진과 관측 정보를 비교, HTML·Excel·API 응답 보존

`configs/1688-first-discovery.example.json`으로 표본 크기를 조정한다. 고정 품목 제외 목록은 없다. 브라우저는 임시 프로필과 전용 Xvfb를 사용하며 개인 데스크톱에 붙지 않는다. 인위적 요청 대기는 0초이고 페이지 준비만 기다린다. 인증/확인 페이지는 해당 경로의 제한으로 기록하고 우회하지 않는다. systemd 실행은 최대 24시간이며 완료 보장 시간이 아니다.

`manifest.json`, `1688-products.json`, `matches.json`, `api-calls.json`, `research.xlsx`, `index.html`, 원문 HTML/JSON이 실행 폴더에 누적된다. `api-calls.json`은 요청 모델과 실제 보고 모델, HTTP 상태, 응답 해시를 구분한다. 유사 상품은 동일 SKU 확정이 아니며 규격/포장/운임 근거 없이 이익을 생성하지 않는다. 월 판매량은 최근 한 달 중복 제거 리뷰 ×15의 근거가 확보될 때 산정하며 현재 탐색만으로 산정하지 않는다.

## 겨울 공산품 범위

`configs/1688-winter-industrial.example.json`은 방풍/단열, 방한 잡화, 보온 생활용품, 차량/야외/작업, 난방/가습, 반려동물/원예 방한의 32개 검색군을 지정한다. 기존 홈페이지 대분류와 별개의 사용자 범위 검색이며 `taxonomy_level=user_scoped_search`로 기록한다. Qwen은 실제 관측 상품명 인용, 겨울 사용 목적(`seasonal_use`), 한국어 핵심 검색어를 반환한다. 식품·의약품·원자재·서비스는 제외하고 전기/배터리/피부접촉 상품의 인증 요건은 미확인 상태를 유지한다.

홈이 로그인으로 이동한 실행은 실패로 보존한다. 이미 관측해 저장한 공식 공개 검색 경로로 검색을 실행할 때는 `inventory_snapshot`과 원문 SHA, `fresh_home_observation=false`를 기록한다. 공개 검색 자체가 인증/확인을 요구하면 중단한다. 기존 전 범주 실행을 중지해도 저장된 상품은 덮어쓰지 않는다.
