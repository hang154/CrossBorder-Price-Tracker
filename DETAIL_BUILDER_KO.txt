작업 순서
  1. 아카이브에서 상품을 선택하고 스타일을 고릅니다.
  2. 상품 기획에서 핵심 요약·타깃·근거 있는 차별점을 입력합니다.
  3. 자동 기획으로 초안을 만들고, 원문과 맞는지 검토합니다.
  4. 24개 블럭·배너 분류에서 구성을 추가하고 제목·본문·사진·좌표를 편집합니다.
  5. Qwen 사진은 원본 참조로 생성됩니다. 상품 형상과 노이즈를 눈으로 확인하세요.
  6. Qwen 모션 기획 또는 등장 순서 자동 배치를 적용합니다.
     제목·본문·사진·카드의 효과, 시작 시간과 길이를 각각 편집합니다.
     타임라인 막대를 끌어 이동·길이 조절하고 재생 위치 슬라이더로 확인합니다.
     12·24·30 FPS, 높음/표준 품질과 540~1000px 너비로 GIF/MP4/WebP를 출력합니다.
  7. PNG 내보내기에서 필요한 마켓을 선택합니다. 쿠팡 780px, 스마트스토어/지마켓 860px,
     11번가 800px, 카카오톡딜 720px, 토스쇼핑 1000px를 지원합니다.
     마켓별 컷 PNG와 860px 원본·HTML·편집 자료를 한 ZIP에 담습니다.
     출력은 제출 시점 버전을 고정하며, 다른 마켓 선택은 별도 폴더에 저장합니다.
     Pencil 편집본 만들기는 별도 버튼으로 실행합니다.
     Pencil은 공식 CLI로 실제 .pen을 생성하고 재열기·PNG 출력을 검증합니다.
     ZIP 결과는 제작 이력에서 내려받습니다.

현재 범위와 제한
  상세 사진이 확보된 상품 아카이브 19개와 겨울 소싱 목록의 587개 변형 상품을
  연결했습니다. 상세 확보/소싱 목록 필터와 상품명·상품번호·분류 검색을 제공합니다.
  목록 상품은 선택한 변형의 대표 사진과 관측 원문을 고정하고 초안을 만듭니다.
  목록 가격·리뷰·배송은 상세페이지의 현재 판매 조건으로 복사하지 않습니다.
  목록 사진은 저해상도일 수 있으며 상세 원문·실측·소재 정보는 별도 확인이 필요합니다.
  6개 스타일, 3개 기본 구도, 18개 상세 분류·6개 배너 분류의 자체 구성을 제공합니다.
  상세뚝딱의 1,000개 이상 템플릿과 전체 편집 기능을 복제한 상태는 아닙니다.
  카피·후기·성능·배송·인증은 판매자 검수가 필요합니다. 일부 위험 문구와 근거 없는
  수치를 차단하지만 자동 기획이 사실을 완전히 보장하지는 않습니다.
  가격·배송·교환 정책을 채우기 전에는 판매용 완성본으로 사용하지 마세요.
  페이지 저장은 버전별로 남으며 동시 수정 충돌은 거절합니다.
  장시간 작업 중 서버를 종료하면 UI 작업 상태의 자동 복구는 미지원입니다.
  Qwen/H3의 작업 ID와 제출 기록은 보존되어 같은 입력으로 재개할 수 있습니다.

H3 연결
  이 PC의 저장 설정: ~/.config/h3_gpu1_edit_api/connection.json (0600)
    {"base":"http://192.168.0.40:18751","interface":"wlo1"}
  키 파일: ~/.config/h3_gpu1_edit_api/api_token.txt (0600)
  H3 서버가 정상이어도 기본 유선 경로로는 시간 초과가 발생했습니다.
  H3 요청의 소켓을 Wi-Fi wlo1에 연결 전에 바인딩하니 인증된 health=ready가 확인됐습니다.
  시스템 라우팅·DNS를 변경하지 않으며 Tailscale은 요구하지 않습니다.
  H3_API_BASE·H3_BIND_INTERFACE 환경변수가 JSON보다 우선하며,
  H3_CONNECTION_FILE로 다른 JSON을, H3_TOKEN_FILE로 기존 키 파일을 지정할 수 있습니다.
  H3_BIND_INTERFACE를 빈 값으로 지정하면 인터페이스 고정을 해제합니다.
  다른 PC는 그 PC의 서버 경로와 인터페이스 이름으로 설정하세요.
  HTTPX 0.28.1 / httpcore 1.0.9에서 인터페이스 연결을 검증했습니다.
  두 상품의 실제 H3 생성·다운로드·한글 모션 합성이 완료됐습니다.
  최종 GIF는 각각 5초·24FPS·120프레임이며 실제 작업 ID와 SHA-256을 보존했습니다.
  서버 원본 MP4는 124프레임·약 5.175초이며 합성 결과는 정확히 5초로 출력했습니다.
  H3 포함 v3.zip에 원본 MP4·합성 GIF·전체 페이지 HTML 검수본을 함께 넣었습니다.
  완료 기록: verification/h3-live-pilots.json / h3-delivery-results.json.
  기존 layer-motion.gif는 한글·사진 레이어 모션으로 5초·24FPS·120프레임입니다.
  text-motion은 이전 12FPS 텍스트 모션이며 두 파일은 H3 생성 결과로 표기하지 않습니다.

Qwen 연결
  기존 app.sourcing_agent.connection()의 등록된 Qwen bearer-file 연결을 사용합니다.
  이미지 인증은 app.qwen_image_api.headers()의 기존 규칙을 사용합니다.
  새 PC는 기존 비밀키 파일과 네트워크 연결을 별도로 설정해야 합니다.
  이미지 작업은 한 번에 하나씩 처리하며 응답 불명 상태에서 자동 재제출하지 않습니다.

새 PC 설치
  Python 3.12+, Chrome, ffmpeg, curl, 한글 Noto 폰트가 필요합니다.
  pip install httpx Pillow openpyxl playwright pytest
  npm install --prefix "$HOME/.local/share/detail-builder-pen" @pen.dev/cli@0.3.13
  export PATH="$HOME/.local/share/detail-builder-pen/node_modules/.bin:$PATH"
  pen login
  현재 렌더러의 Chrome 경로는 /opt/google/chrome/chrome입니다.
  원본 detail.json·사진 아카이브를 복사하고 DETAIL_BUILDER_ARCHIVE로 지정하세요.
  기존 겨울 목록은 sourcing-runs/winter-product-details-20261023/enriched-candidates.json
  경로가 있으면 자동 연결됩니다. 다른 목록은 --list-file 경로로 지정합니다.
  소스 ZIP에는 로그인 정보·키·상품 아카이브·연구용 영상/웹 원문을 넣지 않았습니다.
